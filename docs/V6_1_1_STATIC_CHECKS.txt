Observed true-device exception before SIGABRT:
java.lang.NullPointerException: Parameter specified as non-null is null:
GfnHevcBitstreamProbeVideoDecoder.decode, parameter info

Pinned M144 source contract:
video_decoder_wrapper.cc constructs an empty ScopedJavaLocalRef<jobject> decode_info and passes it to Java_VideoDecoder_decode.
Therefore DecodeInfo is nullable in the real JNI call path despite the unannotated Java interface.

Correction:
GfnHevcBitstreamProbeVideoDecoder.decode(frame, info: VideoDecoder.DecodeInfo?)
The same nullable info is forwarded unchanged; no synthetic DecodeInfo is created.
