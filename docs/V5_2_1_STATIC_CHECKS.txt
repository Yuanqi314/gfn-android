Behavior proven by the fixture
- A transient disconnected state that self-heals inside the grace period performs zero reclaim calls.
- A hard transport failure performs same-session reclaim.
- A failure of a freshly rebuilt transport consumes a bounded retry and still uses the same Session ID.
- Recovery is completed only after FIRST FRAME and input protocolReady.
